# Boston Ball

A minimal browser prototype inspired by the visual and movement language of Hamsterball. It contains one finite checkerboard playground and a procedural low-poly Boston terrier inside a physics-driven ball.

## Run locally

```bash
npm install
npm run dev
```

Controls: WASD or arrow keys to roll and R to reset.

## Build

```bash
npm run build
```

The generated `dist` directory can be deployed directly to Vercel, Cloudflare Pages, or Netlify.
